# Agentmon Three-Form Atlas Prompt Set

These four atlases were authored with the built-in ImageGen workflow, using the installed Form II atlas for each biome as the identity reference. Runtime generation remains disabled.

Shared constraints for every prompt: exactly 16 sprites in a strict row-major 4×4 grid; preserve species identity and ordering from the reference; one centered full-body sprite per cell; generous gutters; no labels, borders, eggs, arrows, extra creatures, or overlap; crisp premium retro pixel art with dark navy outlines; perfectly flat `#ff00ff` chroma background.

## Core Form I

Create juvenile versions of Archive Familiar, Lens Crawler, Prism Monk, Compass Drake, Core Wisp, Relay Jelly, Beacon Beetle, Orbit Moth, Vault Tortoise, Signal Lynx, Rune Serpent, Forge Crab, Scout Rabbit, Oracle Owl, Kernel Golem, and Echo Bat. Simplify anatomy and equipment, shorten limbs, enlarge readable face systems, and keep each silhouette recognizably related to its Form II reference. Do not add Rune Serpent's later orbiting familiar.

## Core Form III

Create mature permanent evolutions of the same sixteen species. Expand anatomy and role-specific equipment: command-grade Archive armor, articulated Lens legs, layered Prism mantle, armored Compass body, expanded Core facets, larger Relay cables, siege Beacon shell, advanced Orbit wings, fortress Vault optics, agile Signal armor, mature Rune segments and familiar, heavy Forge claws, powered Scout gear, full Oracle wings, command Kernel armor, and expanded Echo sonar wings.

## Biome 02 Form I

Create juvenile versions of Tide Axolotl, Scribe Spider, Hammerwake, Prism Peacock, Bore Rhino, Spiral Archivist, Pulse Hummingbird, Abyss Angler, Hex Pangolin, Cinder Ram, Equalizer Frog, Tide Navigator, Razor Mantis, Dew Crane, Key Mimic, and Mycelium Oracle. Use simpler anatomy, smaller role equipment, friendlier proportions, and unmistakable species-specific eyes and silhouettes.

## Biome 02 Form III

Create mature permanent evolutions in the same order: Tide Axolotl with radiant gills and hydro armor; Scribe Spider with a grand scroll archive and articulated claws; Hammerwake with reinforced sonar, naval armor, and heavy treads; Prism Peacock with a contained solar-prism tail; Bore Rhino with multi-stage drill armor; Spiral Archivist with larger archive shell and dual terminals; Pulse Hummingbird with four crystal wings and pulse core; Abyss Angler with deep-sea armor and lantern array; Hex Pangolin with fortress scales; Cinder Ram with turbine horns and ember armor; Equalizer Frog with advanced spring legs; Tide Navigator with rudder and compass instruments; Razor Mantis with reinforced duelist scythes; Dew Crane with stilt legs, lens beak, and teardrop core; Key Mimic as a grand walking vault; Mycelium Oracle with a luminous constellation cap and disciplined root cables.

## Biome 03 Riftwild

The Form II identity atlas introduces Aurora Fox, Moss Colossus, Glacial Whale, Lantern Gecko, Tempest Roc, Magnet Mole, Coral Nautilus, Thunder Bison, Mirror Koi, Chrono Chameleon, Quake Elephant, Nebula Squid, Solar Jackal, Hollow Wyrm, Crystal Bee, and Data Capybara. Each species uses a distinct body, face, sensor system, locomotion, appendage grammar, core, material, and palette.

The Form I prompt preserves those identities while simplifying each into a compact juvenile: shorter limbs and appendages, fewer armor panels, reduced role equipment, and one readable signature motif. The Form III prompt expands each into a permanent mature role with larger authored anatomy and equipment. The egg prompt converts every identity into a distinct shell silhouette, material, seam, core window, and lineage motif while keeping every output visibly unhatched.

All compiled egg and creature sprites subsequently pass through Sprite Fusion Pixel Snapper v1.0.0 using Agentmon's 1–10 strength gauge. Level 4 is the default (2px grid, 160-color ceiling), level 7 reproduces the earlier stronger 3px/96-color treatment, and level 10 is a deliberately hard 6px/48-color grid. Transparent alpha is retained and output is normalized back to 256px with nearest-neighbor scaling.
