# Agentmon Visual Engine V3

V3 replaces unrestricted primitive assembly with curated sprite DNA.

## Rules

- Every hatch belongs to an authored species whose silhouette already meets the reference art direction.
- Each species owns an egg architecture, locomotion system, normal appearance range, attachment anchors, and evolution silhouette.
- Most members of a species look alike. DNA permanently selects the species and individual genes; it does not manufacture arbitrary anatomy.
- Morph expression follows a public deterministic population policy: 85% standard, 10% regional, 4% rare, and 1% mythic.
- Individual genes record size band, screen expression, surface wear, marking gene, and core signature. Skills and equipment create lived individuality after hatching.
- A large theoretical permutation count is not a quality claim. Invalid or visually weak combinations are never renderable.
- Runtime rendering is deterministic, offline, and local. Image generation is an asset-authoring tool, never a background dependency.
- Raw prompts, hidden reasoning, and trainer documents never enter a visual plan or sprite asset.

## Core Founders V1

The first pack contains sixteen founding species with matching eggs. Each species has one standard appearance and deterministic regional, rare, and mythic morphs. The catalogue target is 256 independently authored species; recolors never count toward that target. Each sprite is a 256px transparent PNG derived from the canonical reference direction. The pack manifest records species compatibility and rejects raw Cartesian assembly.

V3 is deliberately narrower than the legacy 64px generator. New species or parts must be authored, reviewed, assigned anchors, tested at game scale, and added through a versioned pack. The legacy renderer remains available only for migration and diagnostics.
